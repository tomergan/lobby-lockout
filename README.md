# Lobby Lockout

A single-floor browser escape puzzle inspired by the original 100 Floors and a real destination-dispatch elevator keypad.

Play at https://tomergan.github.io/lobby-lockout/.

The room and close-up graphics are original generated raster artwork. The puzzle supports touch, mouse and keyboard, four inventory slots, item dragging or tap-to-select, optional hints, sound, saved progress, restart and a complete elevator-opening sequence.

This is a static site: `index.html`, `style.css`, `engine.js`, `game.js`, and `assets/`. No build or dependency installation is required. GitHub Pages serves the main branch. No official game graphics are distributed, and this fan project is not affiliated with the original game.
